# Triglobe frontend

React 19 + TypeScript + Vite SPA for Triglobe Research Analytics.

Stack: [TanStack Router](https://tanstack.com/router) (file-based routes),
[TanStack Query](https://tanstack.com/query) (server state),
[Tailwind CSS v4](https://tailwindcss.com) + [shadcn/ui](https://ui.shadcn.com) (base-vega style).

## Getting started

Requires Node 24 (see `.node-version`).

```bash
npm install
npm run dev     # http://localhost:5173, proxies /api -> http://localhost:8000
```

| Script                    | Purpose                                     |
| ------------------------- | ------------------------------------------- |
| `npm run dev`             | Dev server with HMR                         |
| `npm run build`           | Typecheck (`tsc -b`) then production build  |
| `npm run preview`         | Serve the production build locally          |
| `npm run lint`            | ESLint                                      |
| `npm run format`          | Prettier                                    |
| `npm run generate-client` | Regenerate `src/client` from the API schema |

`generate-client` reads `http://localhost:8000/openapi.json`, so start the API
first. The generated `src/client` is not committed.

## Layout

```
src/
  routes/          file-based routes (__root.tsx is the app shell)
  components/ui/   shadcn primitives — add with `npx shadcn@latest add <name>`
  index.css        Tailwind entry + design tokens
  main.tsx         app entry: router + query client
```

Conventions:

- Files are kebab-case (`research-table.tsx`); React components inside them are
  PascalCase. Route filenames define the URL, so they match the path segment.
- Shared components live in `src/components/`; components used by exactly one
  route live in `src/routes/-components/` (the `-` prefix keeps them out of the
  route tree).
- `routeTree.gen.ts` is generated by the Vite plugin — never edit it.
- Import from `@/…` rather than with relative paths.
